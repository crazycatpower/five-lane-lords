## 魔法

### 1. 法力湧泉（`mana_spring`）

- **類型**：法術（經濟），範圍 C。
- **效果**：範圍內每座我方水晶立刻產出一次（金幣數量等同該水晶一次正常產出），並回復最大生命的 30%。
  - 回血會讓水晶的產出週期變回較快的狀態，產出週期由 `Arcane.crystal_period` 依生命計算。
  - 範圍內沒有水晶時不能施放，比照冥府「沒有墓碑時無法發動」的拒絕方式。
- **AI**：有 2 座以上水晶在同一範圍內、或有水晶生命低於 50% 時使用。
- **定位**：水晶版的豐收，讓魔法經濟多一種主動玩法。

### 2. 連鎖閃電（`chain_lightning`）

- **類型**：法術（遠程）。
- **效果**：先打中落點最近的一名敵人，造成 SS 傷害；再跳向該目標 D 半徑內、還沒被打過的最近敵人，最多再跳 4 次。
  - 每跳一次傷害小一檔：SS → S → A → B → C。
  - 能打部隊、飛行單位與建築，不打城門和領主。
  - 附近沒有下一個目標時就停止跳躍。
- **特效**：在跳躍的目標之間畫鋸齒狀的藍白閃電線，持續 0.3 秒，越後面的跳躍線越細。
- **AI**：範圍內有 3 名以上敵人，或第一個目標是 A 以上生命的重裝單位時使用。
- **定位**：第一下能秒殺重裝，後面的跳躍清小兵。箭雨和火罐則是打一個定點範圍。

### 3. 奧術護盾（`arcane_shield`）

- **類型**：法術（支援），範圍 C。
- **效果**：範圍內每名我方部隊獲得 E（130）的護盾，持續 8 秒（實作時由 B 下修，B 的 560 對 5 費群體法術過強）。
  - 護盾先吸收傷害，扣完才扣生命；新的護盾會覆蓋舊的，不會疊加。
  - 在 `battle.gd` 的 `damage()` 開頭處理，放在護甲和共鳴減傷之後。
- **畫面**：部隊外圍一圈淡藍色光。護盾快用完時變淡，不顯示數字。
- **AI**：我方有 3 名以上部隊正在交戰時，施放在交戰點。
- **定位**：魔法唯一的群體支援，配奧術魔像、閃現劍士往前推。

### 4. 時空力場（`time_field`）

- **類型**：法術（控場），範圍 B，持續 6 秒。
- **效果**：區域內的敵軍移動速度減半，攻擊間隔變成原本的 1.5 倍。
  - 敵軍離開區域就恢復。
  - 不影響建築、城門與領主。
- **畫面**：地上一個緩慢旋轉的時鐘刻度圈；區域內的敵兵動畫也放慢。
- **AI**：敵軍有 4 名以上進入我方半場時，施放在他們前方。

## 經典

### 5. 衝鋒號令（`charge_horn`）

- **類型**：法術（支援），作用於施放的那一整路，持續 6 秒。
- **效果**：這一路所有我方部隊的移速提高一檔，最高到 S。
  - 跟戰鼓手屬於同一類加速，兩者不疊加。
  - 期間新出場的部隊也算在內。
- **畫面**：號角聲；那一路的友軍腳下揚起塵土。
- **AI**：那一路我方有 3 名以上部隊、且正在往前推進時使用。
- **定位**：經典第一張戰鬥法術，符合紅獅的進攻風格。

### 6. 緊急徵召（`levy`）

- **類型**：法術（近戰），點我方領地任何一格即可施放（落點不影響效果）。
- **效果**：施放當下，我方領地內每有 1 名敵方地面部隊，就召喚 1 名民兵（單兵，數值同民兵隊的一員）。
  - 每名民兵出現在它對應敵人的同一路，位置在該敵人和我方城門之間、最靠近敵人的我方格子。
  - 民兵一離開我方領地就消失。消失時不觸發死亡效果，例如詛咒、墓碑加速都不算。
  - 領地內沒有敵人時不能施放，比照冥府「沒有墓碑時無法發動」的拒絕方式。
- **畫面**：民兵從地面的號角光圈中出現；消失時化成一陣塵土。
- **AI**：敵軍有 3 名以上進入我方領地時使用。
- **定位**：敵人越多它越強，是純防守牌；民兵會被領地綁住，不能拿來進攻。

### 7. 投網獵人（`net_hunter`）

| 欄位 | 值 |
|---|---|
| 人數 | 2 |
| 生命 | E |
| 傷害 | F |
| 間隔 | D |
| 射程 | D |
| 移速 | E |

- **類型**：部隊（控場），會射擊。
- **效果**：命中後目標被網住 3 秒，移速減半，沿用 `slow_left`。
  - 同一個目標重複命中只會刷新時間，不會疊加。
  - 對飛行單位無效。
- **定位**：經典自己的遠程兵；不靠傷害，而是拖住騎兵、耕牛、相位騎兵這類快速單位。

### 8. 瞭望塔（`watchtower`）

| 欄位 | 值 |
|---|---|
| 生命 | C |
| 範圍 | A |

- **類型**：建築（遠程），本身不攻擊。
- **效果**：
  - 範圍內的潛行敵人（強盜）一律現形，可以被鎖定。
  - 範圍內我方會射擊的部隊和箭樓，射程提高一檔。
- **畫面**：塔頂有一圈慢慢掃過的光。
- **定位**：反制最強卡組裡的「強盜」，也讓經典的遠程更好用。

## 黑暗

### 9. 獻祭（`sacrifice`）

- **類型**：法術（經濟），範圍 C。
- **效果**：殺死範圍內所有我方部隊，每殺死 1 名得 2 金幣，不超過金幣上限。
  - 不影響建築、領主和敵方部隊。
  - 被獻祭的部隊正常觸發死亡效果。例如腐屍巨人照樣生出骷髏，墓碑照樣因死亡加速。
  - 範圍內沒有我方部隊時不能施放。
- **畫面**：地上浮現血色法陣，被獻祭的部隊化成紅光飛向我方錢袋。
- **AI**：用在快死的部隊（生命低於 30%），或一大群骷髏兵上；範圍內至少要有 3 名。
- **定位**：黑暗的經濟靠犧牲。骷髏兵 6 費 4 隻，獻祭可以換回 8 金，能配合冥府技能、死靈法師和亂葬坑生骷髏的玩法。

### 10. 恐懼嚎叫（`dread_howl`）

- **類型**：法術（控場），範圍 C。
- **效果**：範圍內所有敵方部隊轉身，往自己城門方向逃跑 5 秒，期間不攻擊。
  - 所有部隊一律相同，重裝單位也不例外。
  - 不影響建築與領主。
  - 逃跑期間受到攻擊照常扣血。
- **畫面**：一圈黑色聲波；受影響的敵兵頭上冒出顫抖的小骷髏，逃跑結束時消失。
- **AI**：敵軍有 3 名以上壓到我方城門前 2 格內時使用。

### 11. 亂葬坑（`mass_grave`）

| 欄位 | 值 |
|---|---|
| 生命 | C |
| 週期 | 30 秒 |
| 每次產出 | 骷髏兵 2 隻 |
| 死亡提前 | 5 秒 |

- **類型**：建築（召喚）。
- **效果**：跟墓碑同一套計時機制，只是到點時產出的是骷髏兵，不是金幣。
  - 每 30 秒從坑裡爬出 2 隻我方骷髏兵，沿本路前進。
  - 本路每死 1 名部隊，不分敵我，計時提前 5 秒；超出的時間不保留。這點跟墓碑完全相同，可以直接沿用 `battle.gd` 處理墓碑 `death_advance` 的那段（約第 544 行），把 `kind == "grave"` 擴充成兩種。
  - 它不是常駐牌，也不算冥府技能「亡者大軍」的墓碑。
- **畫面**：
  - 跟墓碑一樣，在建築下方畫一條進度條顯示計時，沿用 `bar()`，顏色用骨白（建議 `d8d0b8`）。
  - 有人死時，一縷魂火飛進坑裡，跟墓碑的提前效果一樣。
  - 不顯示倒數數字。
- **定位**：
  - 墓碑是「死亡換金幣」，亂葬坑是「死亡換兵」。
  - 戰況越激烈，骷髏出得越快，適合放在主戰路。
  - 骷髏是便宜的獻祭材料，可以接著拿來獻祭換錢。
- **AI**：放在我方交戰最多的那一路、領地內偏後的格子；同一路最多 2 座。

### 12. 鮮血塔（`blood_tower`）

| 欄位 | 值 |
|---|---|
| 生命 | C |
| 平時存血 | 每秒 5 點 |
| 死亡存血 | 本路每死 1 名部隊（不分敵我）+50 點 |
| 輸出 | 每秒 20 點 |
| 重新啟動 | 存量用光後，要存到超過 50 點才再輸出 |
| 存量上限 | 500 點（建議值，平衡時再調） |

- **類型**：建築（支援），本身不攻擊。
- **效果**：塔裡存著「血」（治療量），跟墓碑一樣靠時間和本路的死亡累積，但不是一份一份的，而是一個連續的存量。
  - **存血**：平時每秒 +5；本路每死 1 名部隊（敵我都算）+50；最多存到上限。
  - **輸出**：本路有受傷的我方部隊時，每秒從存量拿出 20 點，平均分給本路所有受傷的我方部隊，補到滿血就不再分給它。沒有受傷的友軍時不輸出，存量保留。
  - **用光後**：存量一歸零就停止輸出，要累積到超過 50 點才重新開始。所以存血的速度跟不上時，治療會斷斷續續。
  - 只治療部隊，不治療建築、城門和領主。
  - 實作：塔上存 `blood`（存量）和 `bleeding`（是否正在輸出）兩個欄位。死亡加血接在 `battle.gd` 處理墓碑 `death_advance` 的那段（約第 544 行）。
- **畫面**：
  - 跟農田、墓碑、水晶一樣，在建築下方畫一條進度條，顯示目前存量占上限的比例。沿用 `game.gd` 約第 836–840 行的 `bar()`，顏色用暗紅（建議 `b03a3a`）。
  - 存量低於 50 點、還不能重新輸出時，進度條改成較暗的紅色（建議 `6e3030`）。
  - 有人死時，一滴血飛進塔裡。
  - 輸出時，塔頂有紅色細流沿整路流向受傷的友軍，受治療的部隊身上冒出紅色光點。
- **定位**：
  - 墓碑是「死亡換金幣」，亂葬坑是「死亡換兵」，鮮血塔是「死亡換治療」。黑暗三座建築共用同一種節奏。
  - 平時存著，交戰時持續補整路。戰況越慘烈、死的人越多，它補得越久。
  - 跟草藥婆的差別：草藥婆只補身邊一小塊範圍；鮮血塔補整路，但總量受存血限制。
- **AI**：放在我方交戰最多的那一路、領地內偏後的格子；同一路最多 1 座。
