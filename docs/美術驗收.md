# 美術維護與驗收

## 保留的決策

- 維持羊皮紙中世紀手抄本風格，只維護一套原圖，藍方由程式換色與鏡像。
- 部隊／領主原圖朝右；換色只處理隊色材質，保護皮膚、木頭、泥土與金屬。
- 教學保留純羊皮紙；一般戰場用草地，藍天在頂部 UI，不壓縮場地。
- 兩側高城牆靠近邊緣，表現城堡向畫外延伸；首頁採兩軍對沖、農田與墓碑，不恢復舊城堡首頁。
- 紅獅曾被製作人否決畫風；舊驗收「通過」不能當成定稿認可。

## 修改素材後

1. 原圖與 prompt 存入 `assets/manuscript-v1/`。
2. 執行 `godot_console --headless --path . -s tools/prepare_assets.gd`，再 `godot_console --headless --path . --import`。
3. 檢查 `tools/test_art_palette.gd`；提交原圖、`assets/generated-palette/` 衍生圖與 manifest，不手改衍生圖。
4. 重拍相關場景，檢視原圖與遊戲實際尺寸；必要時使用 `tools/art_audit.gd`。
5. 啟動修改用 `tools/test_startup.gd`；正常啟動只讀預處理紋理，不重做逐像素換色。換色算法改動須更新 `PALETTE_REVISION`。

## 目視檢查

- 肩、手臂、手腕與道具支撐合理；可以遮擋，盾牌不能懸空，不能靠補手掩蓋結構問題。
- 等比縮放、腳底對齊、透明邊緣乾淨；刻意讓城牆延伸畫外不等於意外裁掉人物肢體。
- 紅藍兩方的移動、普攻、投射物、死亡殘影及混編牌都檢查朝向。
- 卡圖、拖曳、登場與死亡保留角色身份；小尺寸仍可辨識用途與隊伍。
- 文字不超框，卡框與花飾完整；功能測試不能取代目視驗收。
