# 錄影模式

從原始專案啟動遊戲（也可雙擊根目錄「錄影模式.cmd」），主畫面選「錄影模式」。先編好牌組，再選「開始錄影對局」，由你控制紅方，電腦控制對手。

打完一局會保存 recordings/match_日期時間.json 與剪輯筆記。在結算頁按「輸出 MP4」，完成後可「開啟錄影夾」。輸出需要 Godot 與 FFmpeg；這是原始專案的本機功能，未重新打包舊版 EXE。

遊玩期間不新增遮擋視野的卡牌特寫。輸出回放時，首次出現的卡牌會顯示實際能力文字，特寫至少相隔七秒。相位騎兵說明鎖定、陷阱、現形與範圍傷害規則，不再重複分類標籤。

在更動遊戲或平衡前先輸出 MP4；回放不是版本快照。平衡檔不同時會拒絕輸出，避免產出錯誤對局。支援此入口的自由對戰，不宣稱可重現冒險、肉鴿或連線特殊規則。
