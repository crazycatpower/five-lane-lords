# 擴充卡表現層審查（2026-11-13）

範圍為 `expansion-source-map.json` 的 46 張正式卡。這是程式事件與繪製路徑審查，不等同人工試玩、音效聆聽或所有畫面驗收。全域數值與 AI 另行量測。

## 本次修正

- 野豬人／叛逃槍騎首撞原本發出沒有 `lane` 的 `slash`，但收割者繪製直接讀取 `e.lane`，會報錯。改為獨立 `charge_impact`，用朝向一致的局部撞擊弧與火花，不再畫三路斬擊。
- 沼澤巨魔只在實際恢復生命時發出治療回饋。
- 治療、維修、護盾、護甲、加速、增程只在有有效對象時發出 `support_pulse`。波紋最多顯示 85 像素，避免支援建築把整片戰場覆蓋；波紋大小不是實際技能範圍提示。
- `sound_bank.gd` 增加衝撞、支援、吸取、召喚事件映射；支援音量較低且有 600 毫秒共用冷卻，避免多建築疊音。既有 `soul/devour/repair/summon` 連線現在有相應音效。
- 上述純視覺事件的額外資料建立受 `record_events` 保護，繪製入口受 `fx_enabled` 保護；使用固定幾何與進度，沒有消耗模型 RNG。

## 還需主整合者處理

1. `game.gd` 的 `draw_effects()` 在算出 progress 後呼叫 `FactionVisuals.event(self,e,progress)`，命中則 continue；入口在關閉特效時直接返回。
2. `expansion_more.gd` 補實際吸血、淨化與貨車死亡／掘墓退費回饋，避免淨化無目標也播放；與 AI 修改同檔，未由本分工同時修改。
3. `consume_events()` 目前關閉特效仍每次掃描民兵追蹤字典；`draw_unit()` 還會算持續狀態動畫；`draw_relations()` 也會算投石車索敵。關閉特效可保留狀態提示，但應跳過純動畫追蹤與重複索敵。
4. 既有骨刺龍反傷沒有來源辨識事件；可用非遞迴的純視覺回刺事件。其傷害不可依賴特效開關。
5. 所有變更合併後統一跑核心測試、擷取特效畫面；不要新增獨立測試檔。
