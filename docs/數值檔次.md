# 數值檔次（SSS–G 十檔）

由 `godot_console --headless --path . -s tools/export_tiers.gd` 從 balance.gd 產生。

基礎生命、傷害、射程、移速、攻擊間隔、範圍及出牌冷卻必須符合檔次；部隊、召喚物、建築與領主均驗證。攻擊間隔與出牌冷卻越小越強。

召喚專用單位不進手牌，冷卻 0 表示不適用；一般卡牌不可使用 0 秒冷卻。費用、數量、百分比、技能持續時間、動畫前搖與戰鬥中增減的生命並非基礎能力檔次。領主技能冷卻與出牌冷卻分開，未套用本次卡牌冷卻表。
