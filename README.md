# 羊皮紙戰記

Godot 4.7.1 五路即時卡牌對戰。匯入 `project.godot` 後執行 `main.tscn`。

Windows 玩家版請到此倉庫的 **Releases** 下載 `FiveLaneLords-Windows.zip`，解壓縮後雙擊 `FiveLaneLords.exe`；不需要安裝 Godot。
匯出設定與驗收限制見 [Windows 打包紀錄](docs/Windows打包.md)。目前是試玩版，尚未通過全部回歸測試。

- 1–4 選手牌，F 選常駐農田；點格子或拖曳出牌，右鍵取消。
- Q 或右下技能按鈕施放領主技能；領主由 AI 移動與作戰。
- 空白鍵暫停；Esc 取消選牌或切換暫停。暫停或結束後按 R 重玩。F11 切換全螢幕；音量在「設定」。
- 牌組為一位領主、常駐專屬經濟牌（手牌 F 格）、自選八張輪轉牌；可選卡牌依領主陣營決定。
- 戰場為九欄五路。部隊與建築只能放己方領地，法術可指定全場。
- 建築本格及周圍八格（含斜角）提供領地，城牆也算。先佔先得；己方仍有建築覆蓋時不能被敵方覆蓋。
- 建築或城牆被毀，失去所有己方覆蓋的格子會釋出；有敵方覆蓋就轉交敵方，否則變中立。重疊的己方建築仍可維持領地。
- 同種己方建築可覆蓋回血。破牆不直接擴張領地；敵兵穿過缺口走入家門即獲勝。
- **一日戰役**：3 分鐘正午金幣 ×1.5、5 分鐘黃昏 ×2、6 分鐘入夜 ×3 且雙方城牆自行朽壞（每分鐘加倍）；9 分鐘天亮仍未分勝負，領地較大者勝。肉鴿不入夜，8 分鐘比城牆血量。
- **冒險模式**是大地圖征服：15 塊領地以道路相連，佔了一塊才能打鄰居；四條支線各有首府，拿下首府可換那位領主出戰，四座都拿下才開放王都。
- 紅獅只在有己方領地的路召喚，豐收只在己方領地空格種田；鐵壁重建城牆可重新取得尚無歸屬的周圍格。
- 新手教學保留純羊皮紙；一般對戰與觀戰用草地，藍天放在頂部 UI。場地為原始尺寸。

規格與開發流程見 `docs/企劃書.md`、`docs/交接給Codex.md`、`AGENTS.md`。

配樂與介面音由 `python tools/make_music.py` 合成（原創、原聲樂器音色），圖示由 `python tools/make_icon.py` 產生。

測試：日常只跑相關專用測試；共用資料修改可跑 `godot_console --headless --path . -s tools/quick_test.gd`。詳見 `AGENTS.md`。
