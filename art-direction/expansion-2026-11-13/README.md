# 新兵種、建築與領主駐守據點素材包

這一包集中保存 2026-11-13 以內建 image_gen 生成的新設計，共 **25 張獨立 PNG**，供後續挑選、修圖與整合。來源依本專案手抄本原圖與提示詞。這是美術提案，尚未加入卡牌、領主或對局邏輯；`.gdignore` 避免 Godot 將草稿當成正式資產匯入。

子文件保留完整生成提示詞、設計用途與已知問題。原始提示詞路徑均指向倉庫根目錄的 `assets/manuscript-v1/`；部分生成紀錄仍記載當時本機資料夾名稱，並非本包內的檔案依賴。

## 與現行遊戲的關係

現行專案有經典、黑暗、魔法、魔物四個陣營及九位領主。魔物原有眼翼龍、腹眼魔、魚喙怪、鬍子魔、鉤鼻飛魔、長身龍、骨刺龍；本包三隻怪物是額外候選，不能取代現有名單。

魔物經濟建築貪食巢穴已存在，其程式是 `glutton_nest.gd`；目前 `balance.gd` 標為 unreleased。這包的孵巢、戰寨及其他經濟用途只作提案，不另立或覆蓋魔物經濟機制。

領主據點是村落、營地或莊園型的駐守目標，收益尚未實作。這批是在舊名單上畫的八處，**尚缺馴獸領主據點**。
